# Server setup

## Installing dependencies

From main repository catalogue, execute command:

```cmd
python -m venv .venv
```


## App setup

### 1. Windows PC

From main repository catalogue, execute command:

```powershell
scripts/setup
```

or

```powershell
powershell ./scripts/setup.ps1
```

### 2. Raspberry Pi 


From main repository catalogue, execute command:

```bash
scripts/setup
```

or

```bash
bash ./scripts/setup.sh
```
